# EQUICAFI Prompt 1 — Engine

Prompt 1 builds the analytical engine. Prompt 2 replaces the dashboard stub with the final product UI/UX.

## Financial language rule
Every metric contains:

- a plain-English explanation;
- the professional definition;
- the formula;
- why it matters;
- a caveat;
- a data-supported observation when one can be made.

## Capital Lab
The scenario engine is hypothetical. It calculates whole-share deployment, remaining cash, final value, profit/loss, ROI and CAGR from user-supplied annual return assumptions.

It does not determine a best investment amount or provide personalized buy/sell recommendations.
